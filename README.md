# Farhana Ayesha | Portfolio

My personal portfolio website, showcasing who I am, my skills, and the projects I build.

🔗Live Demo: https://farhana-portfolio-orcin.vercel.app/

<img width="1902" height="952" alt="image" src="https://github.com/user-attachments/assets/32fdae24-5bf6-415f-8df2-0ed731049b12" />


## ✨ Features

- Fully responsive design (mobile, tablet, and desktop)
- Hero, About, Tech Stack, and Skills sections
- Accessibility support: skip link and reduced-motion handling
- SEO ready: robots.txt, sitemap, and Open Graph image

## 🛠️ Tech Stack

- **Framework:** Next.js
- **Styling:** [Tailwind CSS]
- **Deployment:** Vercel

## 🚀 Run Locally

```bash
git clone https://github.com/farhana-ayesha/farhana-portfolio.git
cd farhana-portfolio
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000) in your browser.
